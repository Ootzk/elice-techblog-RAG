# 실험별 Notebook

`../templates/`의 Notebook을 복사해 실험별 입력 Run·표시 범위·그래프를 설정합니다.
저장된 조건·지표·문항별 기록만 표시하며 보고서에서 해석·결론을 새로 작성하지 않습니다.
커널은 `tools/reporting/.venv`를 사용하며, 실행 출력과 widget 상태를 지운 소스만 커밋합니다.
HTML·실행된 Notebook·다운로드 데이터는 저장소 루트의 `artifacts/reports/`에 둡니다.
상세 실행 방법은 [보고서 도구 문서](../../README.md)를 따릅니다.
